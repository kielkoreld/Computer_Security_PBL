# 출처

## 데이터

- [Bench2Drive 프로젝트](https://github.com/Thinklab-SJTU/Bench2Drive)
- 실제 사용한 배포본: [rethinklab/Bench2Drive-V0.0.4](https://huggingface.co/datasets/rethinklab/Bench2Drive-V0.0.4)
- 고정 데이터 버전: `d84ae18cf20a88b9220df1bc15c073d8824b7ac1`

이 배포본의 44개 시나리오 × 25개 클립, 총 1,100개 클립을 사용했습니다. 별도 Full 배포본의 10,000개 클립이나 공식 폐루프 평가 경로와 같은 집합은 아닙니다. 원본 배포 자료에서 가져온 영상 예제와 메타데이터의 출처는 위 데이터 저장소입니다.

## 모델과 기반 구현

- **Sparse4D / Sparse4Dv3**: [HorizonRobotics/Sparse4D](https://github.com/HorizonRobotics/Sparse4D), 대조 기준 [249ffbb695f4e9db628d953e2bf6d36de04bbb69](https://github.com/HorizonRobotics/Sparse4D/tree/249ffbb695f4e9db628d953e2bf6d36de04bbb69)
- **HiVT**: [ZikangZhou/HiVT](https://github.com/ZikangZhou/HiVT), 대조 기준 [6876656ce7671982ebdc29113aaaa028c2931518](https://github.com/ZikangZhou/HiVT/tree/6876656ce7671982ebdc29113aaaa028c2931518)
- **MMCV**: [open-mmlab/mmcv](https://github.com/open-mmlab/mmcv), 1.7.1 기반 소스
- **탐지 평가 함수**: [nuScenes-devkit](https://github.com/nutonomy/nuscenes-devkit), 1.2.0

관련 코드에는 실제 실행 환경에 맞춘 호환성 수정과 Bench2Drive 데이터를 연결하는 처리가 포함되어 있습니다. 공개 저장소의 기본 실행 결과와 이번 데이터에서 얻은 결과는 구분해야 합니다. 모델 구조·학습·입출력의 설명은 함께 제공한 구현을 기준으로 정리했습니다.

코드를 포함해 전달하므로 원저작권 표기와 배포에 필요한 허가문은 각 코드 폴더에 남겼습니다. 데이터 배포본의 출처·조건은 관련 코드의 데이터 출처 파일에 함께 기록했습니다.
